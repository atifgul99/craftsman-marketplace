# TurboTax Business File Handling

Short reference for working with `.tax20XX` files produced by Intuit TurboTax Business (entity returns) or TurboTax (personal). Invoke when remediating self-prepared returns, diffing as-filed vs. reconstructed, or amending prior years.

## The file formats

| File | Contains | Readable by Claude? |
|---|---|---|
| `.tax20XX` (e.g., `.tax2024`) | Full return workpaper — encrypted Intuit-proprietary binary | **No.** Only opens in TurboTax 20XX desktop (exact year; no forward/backward compatibility). Cannot be read, parsed, or diffed outside TurboTax |
| `_Records.pdf` | PDF export including all forms, worksheets, summaries | **Yes** — `pdftotext -layout` extracts reliably |
| `_Filing.pdf` | The clean PDF that was e-filed (no worksheets) | Yes |
| `~<file>` | TurboTax autosave backup | Same as `.tax20XX` — unreadable; treat as stale and ignore |

TurboTax Business is Windows-only (no native macOS version — runs via Parallels / VM). TurboTax personal is Mac + Windows.

## Working approach — always read the PDF, never the binary

Every number on the filed return is in `_Records.pdf`: page 1 P&L, Schedule K (all lines), Schedule L, M-1, M-2, each issued K-1, depreciation worksheets, carryforward summaries, election disclosures. Parse this; never attempt to open `.tax20XX`.

The `.tax20XX` file is only load-bearing if the user wants to amend **through TurboTax itself** (opens the prior return → "Amend a Return" → e-file or print). Even then: TurboTax Business supports 1065-X but **does not** support Form 8082 BBA AAR, Form 8986, or Form 8978. For BBA amendments the file is useless — prepare the forms manually from IRS fillable PDFs.

Decision tree:
- Reading what was filed? → `_Records.pdf`, always.
- Amending via TurboTax 1065-X (opt-out regime only)? → User opens `.tax20XX` in TurboTax; skill drafts the target workpaper; user keys it in.
- Amending via BBA AAR? → `.tax20XX` file is irrelevant; forms prepared outside TurboTax.

## Amending in TurboTax Business

Open the filed `.tax20XX` file → "File" → "Amend a Return" → TurboTax creates a copy flagged as amended → edit → e-file or print. Important:

- TurboTax Business supports Form 1065-X natively. **Does NOT support Form 8082 AAR** for BBA regime. For BBA AAR, the form must be prepared outside TurboTax and filed separately.
- Forms 8986 and 8978 are not supported in TurboTax Business at partnership level (8978 supported at individual level in TurboTax Premier/Home & Business for the partner's 1040).
- Amended K-1s generated by TurboTax Business have the "Amended K-1" box auto-checked.

For BBA partnerships, the workflow splits:
1. Partnership: use TurboTax Business to **verify the corrected numbers**, then prepare Form 8082 + 8986 manually (PDF fillable from irs.gov).
2. Partners: use personal TurboTax to pick up Form 8978 / Schedule A adjustments on the current-year 1040.

## Parsing `_Records.pdf` into workpaper

Standard flow per [parsing.md](../parsing.md):
- `pdftotext -layout <file>_Records.pdf - | less` for first read.
- The PDF is reliably structured; columns hold. Extract Sch K, Sch L, Sch M-1, Sch M-2, each K-1, depreciation worksheets, carryforward summaries.
- Cache parsed JSON per the schemas (1065-Return, 1120-Return, 1120-S-Return) once added to parsing.md.

## Traps

- **Version drift**: TurboTax 2023 cannot open a TurboTax 2024 file. Keep the matching year installed for any year you might need to re-open.
- **State returns bundled**: state K-1s and state returns live in the same `.tax20XX` file. Deleting / re-running federal amendment does not automatically re-prepare state — verify each state separately.
- **E-file vs. paper markers**: `_Filing.pdf` exists only for e-filed returns. Paper-filed returns produce `_Records.pdf` only. Absence of `_Filing.pdf` is not itself a sign of non-filing; check IRS transcript.
- **Auto-carryforward on amend**: when TurboTax amends TY2023, it does NOT automatically update TY2024's opening numbers. Re-open TY2024 and manually refresh carryforwards from the amended TY2023 close.
- **License re-activation**: older TurboTax versions sometimes fail re-activation after ~3 years. Download installer + license key from Intuit account before attempting; backup now.
- **Cloud sync collisions**: iCloud / OneDrive sync of the `.tax20XX` file while TurboTax has it open produces silent corruption. Close TurboTax, let sync complete, then reopen.
